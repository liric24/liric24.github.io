CacheBlend：RAG 场景下的 KV Cache 复用技术调研

CacheBlend 的核心思想是：”积木式”复用 KV Cache。

在 RAG 场景中，我们将检索到的1个或多个文档拼接成一个长 Prompt 输入给模型。传统的做法是每次都要重新计算整个 Prompt 的 KV Cache，这会导致 TTFT 非常高。CacheBlend 允许我们直接把预先计算好的文档 KV Cache Blend 在一起，通过算法修正位置编码带来的差异，从而跳过繁重的 Prefill 计算阶段。
