Jina-embeddings-v4：多模态多语言检索嵌入模型论文解读

摘要

jina-embeddings-v4 是一个 38亿参数的多模态嵌入模型，通过新颖架构统一了文本和图像表示，支持单向量和多向量嵌入（后交互风格）。该模型结合任务特定的 LoRA 适配器，优化了查询-文档检索、语义文本相似性和代码搜索等场景。

1. 核心贡献

  • 统一多任务学习范式：联合优化文本和图像的单向量/多向量嵌入
  • 任务特定 LoRA 适配器：支持检索、语义相似性、代码搜索三种场景
  • 视觉丰富文档处理：在表格、图表、图解等混合媒体上表现突出
  • Jina-VDR 基准：专为视觉丰富图像检索设计的多语言、多领域基准

2. 模型架构

规格项目 详细信息
模型参数 38亿 + 3个 LoRA 60M（增加<2%显存）
文本输入 最多 32,768 tokens
图像输入 调整为 20 兆像素
单向量嵌入 2048维，可截断到128
多向量嵌入 每个 token 128维

2.1 真正的多模态处理

基于 Qwen2.5-VL-3B-Instruct 骨干网络，与 CLIP 双编码器不同：

  • 图像通过视觉编码器转换为 token 序列
  • 文本和图像由同一 LLM 解码器联合处理
  • 消除了双编码器架构中的模态差距

2.2 双模式输出

  • 单向量：2048维，支持 Matryoshka 截断到 128维
  • 多向量：ColBERT 风格，用于后期交互策略

2.3 LoRA 适配器

适配器类型 应用场景
非对称检索 查询-文档检索
文本匹配 语义相似性、对称检索
代码检索 NL-to-Code、Code-to-Code

3. 训练方法

3.1 两阶段训练

阶段1：对比学习

  • 使用文本对和文本-图像对训练单个 LoRA
  • 采用 InfoNCE 损失 + KL 散度补偿单向量/多向量分布差异

阶段2：任务特定微调

  • 复制阶段1的 LoRA 为三份
  • 使用任务特定三元组分别训练

3.2 联合损失函数

其中是单向量和多向量 softmax 分布的 KL 散度，用于联合优化两种输出模式。

3.3 训练数据

文本-图像对采用多样化策略：

  • 网站截图
  • 渲染的 Markdown 文件
  • 图表、表格
  • 野外混合媒体材料

4. 核心创新：缓解锥形效应

锥形效应：对比学习中不同模态嵌入倾向于形成分离的狭窄锥形簇。

模型 Flickr30K MSCOCO CIFAR-100
OpenAI-CLIP 0.15 0.14 0.20
jina-clip-v2 0.38 0.37 0.32
jina-embeddings-v4 0.71 0.72 0.56

分数越高表示跨模态嵌入重叠度越好，jina-v4 成功缓解了锥形效应。

5. 性能评测

5.1 Jina-VDR 基准（视觉丰富文档）

模型 平均 nDCG@10
jina-embeddings-v3 + EasyOCR 48.97
ColPaLI-v1.2 65.39
DSE-Qwen2-2b-mrl-v1 68.89
jina-embeddings-v4 (single) 75.47
jina-embeddings-v4 (multi) 81.52

5.2 MTEB 性能

任务类别 jina-v4 备注
检索 67.07 通用多模态场景
语义相似度 (STS) 85.89 达到 SOTA
代码检索 71.59 显著提升

6. 总结

jina-embeddings-v4 实现了：

  • 真正的多模态统一：单一模型处理文本、图像、跨模态任务
  • 灵活的输出模式：单向量（高效）+ 多向量（精确）
  • 任务自适应：LoRA 适配器仅增加 <2% 参数
  • 视觉文档处理 SOTA：在 Jina-VDR 上远超其他模型
